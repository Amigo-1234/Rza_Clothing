# RZA Clothing

A responsive storefront for RZA Clothing, a Nigerian clothing brand based in Ikorodu, Lagos.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Built with React, TypeScript, Vite, Tailwind CSS, GSAP, and Lucide icons. Product imagery is in `public/images/rza`.
